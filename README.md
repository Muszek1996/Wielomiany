# Wielomiany

C++ operator overloading exercise: a polynomial class ("wielomian" = polynomial) with a dynamic coefficient array.

- `wielomian.h/.cpp`: `Wielomian` with `=`, `+`, `-`, `*` (by a number and by another polynomial), `<<`, `>>` and a cast to `int` (degree)
- `operatory.h/.cpp`: operator implementations
- `Źródło.cpp`: `main` that runs a demo, then an interactive loop that reads two polynomials and a number and prints their sum, difference and scalar product

## Build
Open `Wielomiany.sln` in Visual Studio and run.
